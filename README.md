# GTonline Database

A relational database implementation for **GTonline**, developed as part of **Assignment 2** for the *Advanced Database Systems I* course.

## Project Description

This project focuses on mapping the given EER (Enhanced Entity-Relationship) diagram of GTonline into a corresponding relational database schema.

The database models users, employers, schools, friendships, interests, and the relationships between these entities.

## Main Entities

The database includes entities such as:

- Users
- Regular Users
- Admin Users
- Employers
- Schools
- School Types
- Friendships
- Interests

The schema also represents relationships such as employment history, education history, user interests, and friendships.
